# Church Love

곡 번호가 영상에 표시되어 있지 않아도 **곡 제목이 같으면** Church Love의 내부 번호로 연결하는 방식입니다.

## 범위
- 통일찬송가: 1~558
- 복음성가: 1001~2999
- 새찬송가: 제외

## 영상 등록 기준
실제 사용할 영상만 등록합니다.
- 반주 음악
- 화면 가사/자막
- 사람의 노래 음성 없음
- YouTube 임베드 가능

영상 제목에 `1번`, `2번` 같은 번호가 반드시 들어갈 필요가 없습니다. 예를 들어 DB의 `1. 만복의 근원 하나님`에 대해 `만복의 근원 하나님 반주 가사` 영상이 확인되면 1번으로 연결할 수 있습니다.

## 자동 누적
1. GitHub Actions가 매일 후보 영상을 제목으로 검색합니다.
2. 후보는 자동 검증 완료 처리하지 않습니다.
3. 실제 확인된 자료만 `verified_sources.json`에 등록합니다.
4. GitHub Actions가 이를 `update_queue.json`으로 옮깁니다.
5. 매일 오전 9시(한국시간)에 검증된 만큼만 `songs.json`에 누적합니다.
6. 하루 최대 100곡이며 10곡이면 10곡만 추가합니다.

잘못된 영상을 억지로 채우지 않는 것이 원칙입니다.
