# Church Love

오늘 초기 DB 300곡:
- 통일찬송가 100곡: 1~100
- 새찬송가 100곡: 1001~1100
- 복음성가 100곡: 3000~3099

영상은 반드시 다음 조건을 확인한 뒤 등록한다.
1. 반주 음악
2. 가사/자막
3. 사람의 노래 음성 없음
4. iframe 재생 가능

확인되지 않은 영상은 `영상 확인 필요` 상태로 남긴다.

`.github/workflows/daily-update.yml`은 매일 실행되며,
`update_queue.json`에 검증 완료된 곡이 있으면 최대 100곡을 자동으로 songs.json에 반영하고 GitHub에 커밋한다.

복음성가 번호 3000~4999는 Church Love 프로젝트의 내부 번호 체계다.
