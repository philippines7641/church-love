# Church Love

교회 찬송·복음성가 웹 반주기 시험판입니다.

## 현재 시험

- 번호 입력
- 곡 검색
- YouTube 영상 임베드
- 16:9 영상 화면
- `songs.json` 기반 곡 DB

## GitHub Pages

Repository의 Settings → Pages에서 Deploy from a branch를 선택하고 `main` / `/ (root)`를 지정하면 웹 주소로 사용할 수 있습니다.

## 주의

현재 `songs.json`의 영상은 시험용입니다. 실제 운영에서는 각 영상의 임베드 가능 여부와 저작권·이용 조건을 확인하고 등록해야 합니다.
