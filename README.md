# Church Love

통일찬송가와 복음성가를 번호 또는 제목으로 검색하고, 검증된 반주+가사 영상을 재생하는 프로젝트입니다.

## 번호
- 통일찬송가: 1~558
- 복음성가: 1001~2999
- 새찬송가: 제외

## 영상 검증 원칙
다음 조건을 모두 확인한 영상만 재생합니다.
1. 반주 음악
2. 화면에 가사/자막 표시
3. 사람의 노래 음성 없음
4. YouTube 임베드 가능

자동 검색은 후보 영상만 찾습니다. 후보를 자동으로 검증된 영상으로 승격하지 않습니다. 이는 잘못된 영상이 Church Love에서 재생되는 것을 막기 위한 것입니다.

## 매일 자동 업데이트
GitHub Actions가 매일 한국시간 오전 9시에 실행됩니다.
- 후보 영상 검색
- 검증 완료 항목 확인
- 검증된 만큼만 songs.json에 누적
- 하루 최대 100곡
- 10곡이면 10곡, 30곡이면 30곡, 0곡이면 0곡

## 주의
YouTube의 실제 음성/가사/임베드 가능 여부를 GitHub Actions만으로 완전하게 판정할 수 없으므로, 자동 검색 결과는 `candidate_queue.json`에만 보관합니다. 실제 확인된 항목만 `update_queue.json`에 넣어야 재생됩니다.
